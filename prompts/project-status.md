Run the PROJECT STATUS operation. Read `vault-config.md` first for vault path and structure.

1. Find all files with type: project in frontmatter
2. Read the current weekly note for project-related todos
3. Check ~/Projects/ for active codebases — list recently modified files across all repos
4. For each project, determine: status (active/stalled/idea), recent activity, next actions
5. Write updated dashboard to the vault's `_llm/status/projects.md`
6. Append to the vault's `_llm/log.md`
7. Open in Obsidian (use vault name from vault-config.md): `obsidian open vault="VAULT_NAME" path="_llm/status/projects.md"`
