Run the DAILY BRIEFING operation. Generate today's Good Morning summary.

1. Get today's date and day of week
2. Read the current weekly note (most recent root-level YYYY-MM-DD.md in ~/Documents/Day to day/)
3. Pull today's date-specific todos (look for [[today's date]] section headers)
4. List incomplete work and life items, flag anything carrying forward 2+ weeks
5. Check ~/Projects/ for recent file modifications (last 3 days) to determine project activity
6. Use backlog rotation based on day of week: Mon=books (To Read.md), Tue=games (Game backlog.md), Wed=blog posts (Tech blog ideas.md), Thu=side projects, Fri=ideas, Sat=creative (DnD, Phaedrus, Music), Sun=life admin
7. Read exercise table from weekly note, note filled vs empty days
8. Read ~/Documents/Day to day/_llm/state/rotation.json, surface next item in today's category, then update the state file
9. If Google Calendar MCP is available, fetch today's and tomorrow's events
10. If Gmail MCP is available, check unread/important emails
11. Add a 'Something to Think About' section — a connection between vault pages, a dormant idea, or a nudge from old notes
12. Write to ~/Documents/Day to day/_llm/daily/YYYY-MM-DD.md (use today's actual date)
13. Open in Obsidian: obsidian open vault="Day to day" path="_llm/daily/YYYY-MM-DD.md"
14. Append to ~/Documents/Day to day/_llm/log.md

Use a warm, concise tone — like a personal assistant briefing over coffee.
